# Notices and provenance

Atlantic 27B v8.2 is a modified Krummholz AI beta derived from Atlantic 27B v8 and Qwen3.8-27B. The Qwen team supplied the pretrained multimodal architecture and upstream weights. Krummholz AI trained the cumulative Atlantic adapter and performed the v8.2 evolution-strategies post-training on the text trunk. The release weights and Krummholz harness code use Apache License 2.0. The model repository includes the upstream license. All original copyright, license and attribution notices apply.

* Base model: Qwen/Qwen3.8-27B, revision `37561816e66b5b9153b1b64c10968c18c1e6f4a0`. [Upstream model and license](https://huggingface.co/Qwen/Qwen3.8-27B/tree/37561816e66b5b9153b1b64c10968c18c1e6f4a0)
* Atlantic v8 cumulative adapter: SHA-256 `5fe08a7b132e23cba1fa6cf8e4957eff0afab09b856c1eae8d51b2e6d76c5802`. We reconstructed the native parent with the pinned Qwen snapshot. The historic adapter names a local base path, so the original merge cannot be identified byte-for-byte from that field. The published v8 Q4_K_M is the reference used in the matched downloadable-file comparison. [Atlantic v8 release](https://huggingface.co/krummholz-ai/atlantic-27b-v8-GGUF/tree/e33a2f8226ad17ee0e53220d3a16f9377879114a)
* Data for the new phase: Wikidata under CC0, U.S. Forest Service Forest Inventory and Analysis records for Maine, and NOAA Fisheries commercial landings. Krummholz constructed paired field questions and misleading labels from those sources. The v8 card describes its earlier training and evaluation sources.
